# Mission: Claude Certified Architect – Foundations (CCA-F)

## Why
Tine is a senior developer (14+ years, Java/TypeScript) who wants to pass Anthropic's **Claude Certified Architect – Foundations** exam within one month, scoring **92%+** (a scaled score of ~920/1000; passing is 720/1000). The certification validates the ability to make production-grade architectural tradeoffs across Claude Code, the Claude Agent SDK, the Claude API, and MCP.

## Success looks like
- Can sit the real exam (60 multiple-choice questions, 120 minutes, scenario-based, 4 of 6 scenarios drawn at random) and score 920+/1000.
- Can explain and apply every task statement in the [official exam guide](../reference/official-exam-guide.pdf) across all 5 domains, not just recognize vocabulary.
- Has hands-on muscle memory for the mechanics the exam tests as "skills in" (not just "knowledge of"): agentic loop control flow, hook-based enforcement, tool description design, CLAUDE.md/rules/skills configuration, JSON-schema structured output, context management patterns.
- Can correctly eliminate plausible-but-wrong distractors under time pressure — the exam is explicitly designed so that a candidate with *shallow* knowledge picks the wrong answer.

## Constraints
- **Timeline**: ~1 month (target exam date: on or before 2026-08-25).
- **Time budget**: 5–7 hours/week (evenings + weekend), so roughly 20–28 hours total study time.
- **Prior experience**: "Some" — has used Claude/Claude Code as a dev tool, called an LLM API a couple of times, but has not built agents, written MCP tools, or done deliberate prompt engineering. Deep general software engineering experience (14+ yrs Java/TS) transfers directly to the mechanics; the gap is Claude/Anthropic-specific patterns, not programming fundamentals.
- Wants a community/study-group resource in the mix, not just solo study (see [[RESOURCES]]).

## Out of scope
Per the official exam guide's own "Out-of-Scope Topics" list — do not spend study time on: fine-tuning, API auth/billing/rate-limits, cloud provider (AWS/GCP/Azure) specifics, MCP server hosting/infrastructure, Claude's internal architecture/training/RLHF, embeddings/vector DBs, computer use, vision, streaming API internals, prompt caching internals, or tokenization algorithms.
